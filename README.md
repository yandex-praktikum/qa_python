# qa_python

## Реализованные тесты

### Добавление новых книг
- проверка, что книга с пустым названием не добавляется;
- проверка, что книга со слишком длинным названием не добавляется;
- проверка, что дубликат книги не добавляется повторно;
- проверка успешного добавления книги с корректным названием.

### Установка жанра книги
- проверка, что жанр не устанавливается для несуществующей книги;
- проверка, что книге не устанавливается недопустимый жанр;
- проверка, что жанр не устанавливается при одновременной невалидности книги и жанра;
- проверка успешной установки жанра существующей книге.

### Получение жанра книги
- проверка получения корректного жанра книги;
- проверка возврата `None` для несуществующей книги.

### Получение списка книг по жанру
- проверка получения списка книг с определённым жанром;
- проверка возврата пустого списка для жанра без книг;
- проверка возврата пустого списка для несуществующего жанра.

### Получение словаря книг и жанров
- проверка возврата словаря `books_genre`.

### Получение книг для детей
- проверка, что возвращаются только книги без возрастного рейтинга.

### Работа с избранными книгами
- проверка добавления книги в избранное;
- проверка, что дубликат книги не добавляется в избранное;
- проверка, что несуществующая книга не добавляется в избранное;
- проверка удаления книги из избранного;
- проверка, что удаление несуществующей книги из избранного не вызывает ошибок;
- проверка получения списка избранных книг.
