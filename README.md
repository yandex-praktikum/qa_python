# qa_python

test_add_new_book_add_two_books — проверяет успешное добавление двух разных книг в коллекцию

test_set_book_genre_positive — параметризованный тест, проверяет корректное присвоение валидных жанров («Комедии», «Фантастика», «Детективы») добавленным книгам.

test_set_book_genre_negative — проверяет, что несуществующий в системе жанр («Приключения») не присваивается книге, и её жанр остаётся пустой строкой.

test_get_book_genre — проверяет, что метод правильно возвращает жанр конкретной книги («Фантастика» для «Дюны»).

test_get_books_with_specific_genre — проверяет фильтрацию книг: при запросе жанра «Комедии» возвращается только «Золотой теленок», а «Дракула» (Ужасы) игнорируется.

test_get_books_for_children — проверяет, что книги с жанрами «Ужасы» и «Детектив» отсекаются, а книги жанров «Мультфильмы» и «Комедии» успешно возвращаются.

test_add_book_in_favorites — проверяет, что книга успешно добавляется в список favorites.

test_delete_book_from_favorites — проверяет, что после добавления двух книг и удаления одной из них («Дон Кихот»), в списке избранного остаётся только вторая («Ходячий замок»).

test_get_list_of_favorites_books — проверяет, что метод возвращает корректный список всех добавленных в избранное книг.
